# Шпаргалка по сайту БумБастик

## Самое главное

В папке проекта лежат два файла-ярлыка. Запускаются **двойным кликом** из Finder:

| Файл | Что делает |
|---|---|
| `🚀 Запустить сайт.command` | Включает локальный сайт и открывает его в браузере |
| `📤 Опубликовать.command` | Отправляет изменения на b00m.fun |
| `🔑 Настроить доступ.command` | Разовая настройка доступа к GitHub |

Терминал открывать не нужно.

**При первой настройке компьютера** запустите `🔑 Настроить доступ.command` — он поможет создать токен GitHub и сохранит его в связке ключей. Больше логин и пароль спрашивать не будут.

---

## Как обычно работать

1. **Двойной клик** по `🚀 Запустить сайт.command`
   Откроется окно Терминала и браузер с адресом http://localhost:5173
   Это ваша личная копия сайта — её видите только вы.

2. **Правите тексты** в `.md` файлах (через Claude Desktop или любой текстовый редактор).
   Сохранили файл → страница в браузере обновилась сама. Ничего перезапускать не надо.

3. Когда всё нравится — **двойной клик** по `📤 Опубликовать.command`
   Он покажет, что изменилось, и спросит подтверждение:
   - `д` — публиковать
   - `п` — сначала посмотреть правки в GitHub Desktop
   - `н` — отмена

   Затем спросит, что вы изменили. Напишите пару слов и нажмите Enter.

4. Через 1–2 минуты изменения появятся на **https://b00m.fun**
   Проверить сборку: https://github.com/mihail-izumov/boombastic/actions

5. Закончили на сегодня — закройте окно Терминала (или нажмите в нём `Ctrl+C`).

## Что где лежит

| Путь | Что это |
|---|---|
| `index.md` | Главная страница |
| `parks.md`, `prizes.md`, `charge.md`, `rewards.md`, `terms.md` | Основные страницы сайта |
| `Parks/` | Страницы конкретных парков |
| `prizes/` | Страницы призов |
| `public/` | Картинки, иконки, файлы (доступны по адресу `/имя-файла`) |
| `.vitepress/config.mts` | Настройки сайта: меню, заголовок, иконки |
| `.vitepress/theme/` | Оформление, стили |
| `.vitepress/components/` | Блоки-компоненты (модальные окна и т.п.) |

**Не трогайте:** `node_modules/`, `.vitepress/dist/`, `.vitepress/cache/` — это служебные папки, создаются автоматически.

## Команды в терминале (если ярлыки не сработали)

Сначала всегда перейти в папку проекта:

```
cd ~/work-2026/boombastic/boom-fun
```

| Команда | Что делает |
|---|---|
| `npm run docs:dev` | Запустить локальный сайт (http://localhost:5173) |
| `npm run docs:build` | Проверить, что сайт собирается без ошибок |
| `git status` | Показать, какие файлы изменены |
| `git add . && git commit -m "описание" && git push` | Опубликовать изменения |
| `git pull` | Забрать изменения с GitHub (если правили через сайт GitHub) |
| `Ctrl+C` | Остановить локальный сайт |

## Если что-то сломалось

**Страница в браузере не грузится / «не удаётся подключиться»**
Локальный сервер не запущен. Двойной клик по `🚀 Запустить сайт.command`.

**Правки не видно в браузере**
Обновите страницу (`Cmd+R`). Если правили `.vitepress/config.mts` — закройте Терминал и запустите сайт заново.

**В Терминале красный текст с ошибкой**
Скопируйте текст и покажите Claude — разберёмся.

**Публикация прошла, но на b00m.fun ничего не изменилось**
Подождите 2 минуты. Потом проверьте https://github.com/mihail-izumov/boombastic/actions — если там красный крестик, сборка упала.

**При публикации: «refusing to allow a Personal Access Token to update workflow»**
Правился файл публикации `.github/workflows/deploy.yml`, а у токена нет на это права. Откройте https://github.com/settings/tokens → нажмите на токен «Mac mini boombastic» → поставьте галочку **workflow** → внизу **Update token**. Токен останется тем же, заново вводить его не нужно. После этого запустите `📤 Опубликовать` ещё раз. Правки при этом не потеряны: коммит уже сделан, не хватило только отправки.

**Хочу посмотреть историю изменений или откатить старую правку**
Откройте GitHub Desktop — там видно всю историю по файлам и можно отменить любой коммит.

**Хочу откатить всё, что наделал (до публикации)**
```
cd ~/work-2026/boombastic/boom-fun
git checkout .
```
Внимание: это удалит все несохранённые правки безвозвратно.
